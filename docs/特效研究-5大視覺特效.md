## 1. 鏡面無限反射（mirror / infinite reflection）

### 簡單版（純 CSS / SVG，無 WebGL）
- **地面倒影（最平）**：物件下方一個 `transform: scaleY(-1)` 的複製 + `mask-image: linear-gradient(to bottom, rgba(0,0,0,.6), transparent)` + 輕微 `filter: blur(1px)`，就做到「琉璃地板」倒影，`opacity` 控制強度。
- **CSS 無限隧道（兩鏡互照的幻覺）**：用 `transform-style: preserve-3d` 把多個漸細、漸透明、間距遞增的同心邊框層疊，配 `repeating-conic-gradient` 或 `repeating-radial-gradient` 做「LED 無限鏡」光紋。
- 核心 CSS 關鍵字：`transform-style: preserve-3d`、`-webkit-box-reflect`（僅 WebKit，已非標準，僅作 fallback）、`backdrop-filter`。
- 用途建議：商品卡 hover 倒影、hero 底下「深淵鏡面」。

### 進階版（Three.js / R3F）
- **主力 = `@react-three/drei` 的 `MeshReflectorMaterial`**：任何 mesh 上一層平面反射材質，內部用一個 reflection camera + `WebGLRenderTarget` 做平面鏡（mirror），支援 `blur`／`roughness`／`mixBlur` 做出「鏡面 → 磨砂玻璃」過渡。關鍵 props：`mirror`（0 = 貼圖色、1 = 環境色）、`blur`、`mixBlur`、`mixStrength`、`resolution`（反射 render 解析度）、`metalness`、`roughness`、`depthScale`。
  ```jsx
  import { MeshReflectorMaterial } from '@react-three/drei'
  <mesh rotation={[-Math.PI / 2, 0, 0]} position={[0, -1, 0]}>
    <planeGeometry args={[12, 12]} />
    <MeshReflectorMaterial
      blur={[300, 100]} resolution={2048} mixBlur={1} mixStrength={40}
      roughness={0.4} mirror={0.6} depthScale={1.2} color="#10100F" metalness={0.6}
      minDepthThreshold={0.4} maxDepthThreshold={1.4}
    />
  </mesh>
  ```
- **真正「兩鏡互照」無限反射**：three.js 原生 `Reflector`（`three/examples/jsm/objects/Reflector.js`）內部有 `getRenderTarget()` 同 `renderWithMirror` 邏輯，理論上可「鏡中鏡」遞迴。**但 three.js 唔會做無限遞迴**——兩鏡互望會指數級成本，官方 issue 明示「infinite renders 冇可能 60fps」，只會 render 有限 bounce（通常 1 層，之後就係上一 frame 的近似）。
- 落地手法：**有限遞迴／假遞迴**——用兩塊 `MeshReflectorMaterial` 面對面，靠 `resolution` 調低、`blur` 調高去「欺騙」眼睛；要真正多層就用 render-to-texture 手動遞迴（render scene → FBO → 再 render 鏡面 sample 個 FBO），遞迴深度 2–3 已夠。
- 真正「物理無限反射」要靠 SSR / ray-tracing（`three.js` 全局 docs 有 SSR `stochastic` 參數），嗰個成本極高，不建議做商品站。

### Library / Repo
- [`MeshReflectorMaterial` 官方 docs](https://drei.docs.pmnd.rs/shaders/mesh-reflector-material)
- [three.js 鏡面官方 demo（Reflector）](https://threejs.org/examples/webgl_mirror.html)
- [Reflector 教學（無限鏡 = 兩塊 Reflector 面對面）](https://sbcode.net/threejs/reflector/)
- [three.js issue #12098：多鏡 recursion 殺效能](https://github.com/mrdoob/three.js/issues/12098)
- [three.js issue #3856：`renderWithMirror` 鏡中鏡做法](https://github.com/mrdoob/three.js/issues/3856)
- [StackOverflow：用 Reflector 模擬真正鏡面](https://stackoverflow.com/questions/20378713/create-or-simulate-actual-mirror-using-threejs)

### 效能考量
- **貴位**：每塊反射面 = 場景多 render 一次（反射貼圖重畫）。兩鏡互照遞迴 = 幾何級數爆。
- **降級**：`resolution` 由 2048 → 1024／512；`blur` 拉高掩蓋低解析；`mixBlur` 磨砂化；只用「單面」反射（floor mirror）唔好兩鏡互照；mobile 直接跌落「簡單版」CSS 倒影。

## 2. 琉璃折射（glass refraction / SSS / transmission / chromatic aberration 色散）

### 簡單版（純 CSS / SVG，玻璃擬態 glassmorphism）
- CSS `backdrop-filter: blur(12px) saturate(160%)` + 半透明底 `background: rgba(132,94,194,.12)` + 內外兩層 `box-shadow`（內陰影做厚度）+ `border: 1px solid rgba(255,255,255,.2)`，就係「琉璃卡片」。
- **色散（chromatic aberration）用 SVG filter 模擬**：`feOffset` 拆 RGB 三通道做 1–2px 錯位 + `feBlend` 疊返，做出琉璃邊緣的藍紫 fringing。
- **折射扭曲**：`feTurbulence` + `feDisplacementMap`（同 §3 焦散同源，`scale` 校細就好似玻璃折射）。
- 用途建議：導覽玻璃 bar、商品卡、hero 標題背後的琉璃 panel。色散貼合主題色：邊緣用 `#845EC2`（紫）→ `#00B4D8`（青）對補。

### 進階版（Three.js / R3F）
- **主力 = `@react-three/drei` 的 `MeshTransmissionMaterial`**：`MeshPhysicalMaterial` 的增強版，原生支援 `transmission`／`thickness`／`ior`／`roughness`，仲加咗 **`chromaticAberration`（色散 fringing）、`anisotropicBlur`（單向拉絲 blur）、`attenuationColor`/`attenuationDistance`（體積吸光染色）**，而且同原生傳輸材質唔同，佢**可以「睇穿」其他傳輸／透明物件**（連層折射）。
  ```jsx
  import { MeshTransmissionMaterial } from '@react-three/drei'
  <MeshTransmissionMaterial
    transmission={1}          // 光穿透度
    thickness={0.5}           // 玻璃體厚度 → 折射深度
    ior={1.5}                 // 折射率（琉璃/玻璃 ~1.5）
    chromaticAberration={0.03}// 色散 fringing
    anisotropicBlur={0.1}     // 拉絲磨砂
    roughness={0.15}
    attenuationColor="#845EC2"   // 體積吸光染紫晶色
    attenuationDistance={2}
    backside                   // 渲染背面（玻璃厚度感）
  />
  ```
- **次表面散射 SSS**：three.js addon `SubsurfaceScatteringShader`（`import { SubsurfaceScatteringShader } from 'three/addons/shaders/SubsurfaceScatteringShader.js'`），基於 GDC 2011「Approximating Translucency」；配 `ShaderMaterial` 直接餵 `uniforms`。更高階走 physical 路：`SSSLightingModel`（`sss: true` 旗標）+ `MeshPhysicalMaterial` 的 `thickness`。
- **後製色散（全畫面）**：`@react-three/postprocessing` 的 `ChromaticAberration`（包住 `postprocessing` 的 `ChromaticAberrationEffect`），在 `EffectComposer` 內：
  ```jsx
  import { EffectComposer, ChromaticAberration, Bloom } from '@react-three/postprocessing'
  import { BlendFunction } from 'postprocessing'
  <EffectComposer>
    <ChromaticAberration blendFunction={BlendFunction.NORMAL} offset={[0.02, 0.002]} />
    <Bloom intensity={0.4} luminanceThreshold={0.85} />
  </EffectComposer>
  ```
- 琉璃新藝術的「透光染色」關鍵：`attenuationColor` 用 `#845EC2`（紫晶）+ 焦散光用 `#00B4D8`（青藍）做 rim，就係「紫晶透光」的物理對應。

- [MeshTransmissionMaterial DeepWiki 詳解](https://deepwiki.com/pmndrs/drei/2.2.1-meshtransmissionmaterial)

### 效能考量
- **最貴位**：`transmission` 係把畫面先 render 到 transmission buffer 再折射 sample（≈ 場景多 render 一次）；`backside` + 多層玻璃會再疊加；`anisotropicBlur` 每個 pixel 多幾次 blur sample。
- **降級**：mobile 關 `anisotropicBlur`、`chromaticAberration` 減到 0；玻璃面解析度靠 `resolution` prop 降；或直接「簡單版」`backdrop-filter`。SSS 只在單一 hero 主體用，唔好成場用。

## 3. 水面焦散（water caustics，有機網狀流體光紋）

### 簡單版（純 SVG，`feTurbulence` + `feDisplacementMap`）
- **核心**：`feTurbulence`（`fractalNoise`，低 `baseFrequency`）生成 Perlin noise → 餵俾 `feDisplacementMap` 做像素位移 → 疊返 linearGradient 光紋，就係流體焦散。用 `<animate>` 動 `baseFrequency` 或 `seed` 就「流動」，零 JS。
- **「有機網狀光紋」關鍵**：低 `baseFrequency`（`0.01–0.03`）＋中高 `scale`（`20–50`）→ 闊水面狀扭曲；要「網狀 caustic ring」再加 `feMorphology`（erode 形狀）做邊緣高光。
  ```html
  <filter id="caustics">
    <feTurbulence type="fractalNoise" baseFrequency="0.012 0.02" numOctaves="2" seed="8" result="noise">
      <animate attributeName="baseFrequency" dur="8s"
               values="0.012 0.02; 0.018 0.028; 0.012 0.02" repeatCount="indefinite" />
    </feTurbulence>
    <feDisplacementMap in="SourceGraphic" in2="noise" scale="28"
                       xChannelSelector="R" yChannelSelector="G" />
  </filter>
  ```
  光紋色用主題色 gradient：白 → `#00B4D8`（琉璃青藍焦散）→ 透明。用途建議：hero 背景「水面」、section 之間的光紋過場。

### 進階版（Three.js / R3F / shader）
- **主力 = `@react-three/drei` 的 `<Caustics>`**：把傳輸／折射幾何體（玻璃瓶、水面 mesh）放入 caustics 場景，用 **raymarching（反向 Snell 折射）** 把焦散投影到一個「catcher plane」（面向 Y 上），再 blend 入主場景。基於 [github/N8python/caustics](https://github.com/N8python/caustics)。關鍵 props：`ior`（折射率）、`backsideIOR`、`worldRadius`（texel 大小）、`intensity`、`color`、`resolution`（buffer 解析度）、`lightSource`（光源位置或 ref）、`frames`（`1` = 只算一次靜態；`Infinity` = runtime 動態）、`debug`。
  ```jsx
  import { Caustics } from '@react-three/drei'
  <Caustics backside lightSource={[2.5, 5, -2.5]} ior={1.4} backsideIOR={1.1}
            intensity={0.3} worldRadius={0.3125} color="#00B4D8" resolution={1024}>
    <WaterMesh />      {/* 傳輸/折射幾何體 */}
  </Caustics>
  ```
- **流動水面焦散（全 shader）**：`dgreenheck/threejs-water-shader` 有獨立 caustics fragment shader；學術正統做法 = GPU Gems 第 2 章「Rendering Water Caustics」：水面 heightfield + normal → 由 floor 反向 trace 光線經 Snell's law → 焦散亮斑。開源實作：`arch-19/Water-And-Caustics`（Evan Wallace WebGL Water 啟發，backward ray tracing + inverse Snell）。
- 要「有機網狀」紋理，可再疊一個細 `feTurbulence` 生成的 caustics texture 做 `map`。

### 效能考量
- **貴位**：drei `Caustics` raymarching 用低 `resolution` buffer 可以接受（預設 2048，建議 mobile 512–1024）；`frames={Infinity}` 動態重算最貴，靜態 `frames={1}` 幾乎零持續成本（算一次）。
- **降級**：mobile 用「簡單版」SVG 焦散（CPU/GPU 都好輕，甚至可離屏烘焙成 GIF/WebM loop）；或把焦散預先 render 成一張 caustics texture 直接 `map` 上地板。

## 4. 花海粒子（floral particle field，InstancedMesh / shader 花瓣漂浮）

### 簡單版（純 CSS / SVG / Canvas 2D）
- **CSS**：多個絕對定位花瓣（SVG path 或 emoji 花瓣）各自 `@keyframes` 漂浮（`translateY` + `rotate` + `scale`）+ 不同 `animation-delay`／`duration` 隨機化；`filter: blur()` 做景深。
- **Canvas 2D（進一階）**：一個 `requestAnimationFrame` loop 畫 N 個花瓣 sprite，用 `ctx.globalCompositeOperation = 'lighter'` 做發光疊加；比 DOM 快，但 N > 幾百就吃力。
- **Motion（framer-motion 13）**：`<motion.div animate={{ y: [0,-30,0], rotate: 360, opacity:[0,1,0] }} transition={{ repeat: Infinity, duration: 8, delay: i*0.3 }} />` 快速起幾十粒。
- 用途建議：hero 散落花瓣、loading、footer 微氛圍。

### 進階版（Three.js / R3F / shader）
- **主力 = `THREE.InstancedMesh`**：一片花瓣 geometry × N 個 instance，**1 個 draw call**。每個 instance 有自己 4×4 matrix（`setMatrixAt`），加 `setColorAt` 上花色。
- **GPU 漂浮動畫（唔郁 CPU）**：用 **`InstancedBufferAttribute`** 塞 `aPhase`／`aSpeed`／`aTilt`／`aSeed` 入 geometry，vertex shader 讀佢哋做 sway——花瓣「根」固定、「尖」擺動（用 `uv` 做 tip weight），N 去到幾萬都 60fps。
  ```js
  const geo = petalGeometry.clone()
  const phases = new Float32Array(count), speeds = new Float32Array(count)
  for (let i = 0; i < count; i++) { phases[i] = Math.random()*Math.PI*2; speeds[i] = 0.5 + Math.random()*1.5 }
  geo.setAttribute('aPhase', new THREE.InstancedBufferAttribute(phases, 1))
  geo.setAttribute('aSpeed', new THREE.InstancedBufferAttribute(speeds, 1))
  const mesh = new THREE.InstancedMesh(geo, shaderMaterial, count)
  ```
  ```glsl
  // vertex shader 關鍵
  attribute float aPhase; attribute float aSpeed; uniform float uTime;
  float tip = smoothstep(0.0, 1.0, uv.y);           // 尖端權重
  float sway = sin(uTime * aSpeed + aPhase) * 0.1 * tip;
  position.x += sway; position.z += cos(uTime*aSpeed*0.7 + aPhase)*0.06*tip;
  ```
- **R3F 快速版**：`@react-three/drei` 的 `<Instances>`／`<Instance>`（React 宣告式，limit/range 控上限）做大量花；**純光點漂浮**用 `<Sparkles>`（size／speed／color，直接出 `#00B4D8` 光塵）；單一柔化點用 `Points` + `PointsMaterial`（`map` 圓形 sprite、`transparent`、`depthWrite:false`、`blending: AdditiveBlending`）。
- **花瓣 shader 材料**：`MeshPhysicalMaterial` 太貴，用 `ShaderMaterial`（半透明 + `side: DoubleSide` + 自訂 alpha fade + rim light 做琉璃感）或 `MeshStandardMaterial` `transparent`；花瓣用 additive blending 出「發光花海」。

### Library / Repo
- [three.js `InstancedMesh` docs](https://threejs.org/docs/pages/InstancedMesh.html)
- [InstancedMesh 指南：百萬物件 60fps / 1 draw call](https://www.mysimulator.uk/content/tutorials/instancedmesh-guide.html)
- [Federico Toledo：InstancedMesh 草地（vertex shader 有機擺動）](https://lab.federicotoledo.dev/three-js-journey/grass)
- [TroisJS `InstancedMesh`（setMatrixAt 流程）](https://troisjs.github.io/guide/meshes/instanced)
- [drei `Sparkles` docs](https://drei.docs.pmnd.rs/staging/sparkles)

### 效能考量
- **InstancedMesh = 最平**：1 draw call 畫 N；樽頸係 overdraw（半透明花瓣重疊）同 vertex 數量，唔係 instance 數。
- **降級**：花瓣 geometry 面數壓到 ~2 triangles（billboard quad + alpha texture）；mobile 用 `Points`（光點）代替實體花瓣、或「簡單版」Canvas 2D；`dpr` 上限 1。

## 5. 新藝術金絲線條（Art Nouveau filigree，SVG path 描邊動畫 + pathLength）

### 簡單版（純 CSS / SVG / Motion）
- **描邊動畫核心 = `stroke-dasharray` + `stroke-dashoffset`**：設 `stroke-dasharray` = 路徑全長、`stroke-dashoffset` = 全長（藏起），animate offset → 0（畫出嚟）。用 **`pathLength="1"`** 把路徑長度歸一化，`stroke-dasharray:1; stroke-dashoffset:1` 就通用，唔使 JS 量 `getTotalLength()`。
  ```html
  <path d="M..." pathLength="1" style="stroke-dasharray:1; stroke-dashoffset:1" />
  <style>
    path { fill:none; stroke:#00B4D8; stroke-width:1.5; animation: draw 3s ease forwards; }
    @keyframes draw { to { stroke-dashoffset: 0; } }
  </style>
  ```
- **Motion 版（推薦，已喺 stack）**：`<motion.path initial={{ pathLength: 0 }} animate={{ pathLength: 1 }} transition={{ duration: 2.5, ease: "easeInOut" }} />`——Motion 內建 `pathLength`，直接做描邊，仲可配 `useScroll` 做 scroll 觸發。
- **金絲質感**：`stroke` 用漸變（`linearGradient` 金 → 白）＋第二條細 `stroke` 做內高光；要「金絲」可 `#d4b483`→`#f3e7c9`。新藝術捲鬚 = 多條 `C`（cubic bezier）曲線，`stroke-linecap: round`。
- 用途建議：開場 logo 描邊、section 分隔捲鬚、商品頁邊框 filigree。

### 進階版（Three.js / R3F）
- **3D 金絲線**：`@react-three/drei` 的 `<Line>`（基於 three-stdlib `Line2` / `LineMaterial`，可做可變寬、`linewidth`、`worldUnits`）；或 `TubeGeometry` 沿 `CatmullRomCurve3` 做真 3D 管狀金絲（有體積、可上 `MeshPhysicalMaterial` 金屬）。
- **shader 描邊（draw-on）**：用 `fadeSize`／`dashOffset` uniform 沿 U 座標做 reveal——fragment shader 用 `vU.x` 同 `uProgress` 比對，`step(uProgress, vU.x)` 決定畫到邊度；配 emissive + `AdditiveBlending` 出「幽玄金絲發光」。drei `<Line>` 本身有 `dashed` 同 `dashOffset` 可動。
- **線條流動光**：把 §3 的 `feTurbulence` 或一張流動 gradient 做 `map`，令金絲有流動反光。

### 效能考量
- **簡單版極平**：SVG stroke 動畫係合成器加速，`pathLength` 歸一化免 JS 量測；大量 path 同時描邊先要限流（分批 `transition-delay`）。
- **進階版**：`Line2`/`TubeGeometry` 貴在幾何體頂點數；金絲線條數要控制（十條內）。mobile 用 SVG 版，只有 hero 主 logo 先上 3D 管狀金絲。

## 6. 效能總覽 + 分級落地建議

| 特效 | 最貴位 | 簡單版成本 | 進階版成本 | mobile 建議 |
|---|---|---|---|---|
| 鏡面無限反射 | 反射面每塊 = 多 render 一次；兩鏡互照 = 幾何級數 | 近乎零 | 高（多 pass） | CSS 倒影／單面反射 |
| 琉璃折射 | transmission buffer（多 render 一次）+ 色散 blur sample | 零（backdrop-filter） | 高 | backdrop-filter；關 anisotropicBlur/SSS |
| 水面焦散 | raymarching（動態 frames=Infinity 最貴） | 極低（SVG filter） | 中（靜態 frames=1 近乎零） | SVG 焦散／烘焙 caustics texture |
| 花海粒子 | overdraw（半透明重疊） | 低（<幾百） | 低–中（1 draw call） | Points 光點／Canvas 2D |
| 金絲線條 | 3D 管狀幾何頂點數 | 極低 | 低 | SVG 版；僅主 logo 上 3D |

**落地優先順序（用最少成本攞最大視覺衝擊）：**
1. **金絲線條（SVG + Motion pathLength）** — 成本最低、最貼「新藝術」、開場即見。
2. **水面焦散（SVG feTurbulence 做背景）** — 近乎免費，用 `#00B4D8` 光紋立刻有「幽玄」。
3. **琉璃折射（簡單版 backdrop-filter 卡片）** — 玻璃擬態 + `#845EC2` 透光染色。
4. **花海粒子（InstancedMesh）** — 進階版但成本可控，hero 主視覺。
5. **鏡面無限反射（MeshReflectorMaterial）** — 最後加，只做單面 floor mirror，mobile 跌落 CSS。

**「幽玄」關鍵一招**：全站後製疊一層 `@react-three/postprocessing` 的 `Vignette` + 低強度 `ChromaticAberration`（`offset` 極細）+ `Noise`（film grain），用 `#845EC2`／`#00B4D8` 做兩端色差，成個網即刻有「暗夜 × 琉璃 × 幽玄」統一度。
