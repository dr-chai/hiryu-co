## 0. 一句定位

**輝琉（HIRYU）＝ 廢佬（劉輝）由「廢」走到「輝」嘅化身。**
「可負擔嘅日常選物店」——用頂級視覺規格，賣平凡但有眼光嘅好物。

---

## 1. 品牌故事

- 「輝琉」＝「劉輝」反轉；「廢佬」係自嘲，亦係提醒自己唔好放棄。
- 核心轉化：**廢（自我懷疑、未被看見）→ 輝（被理解、被選中、發光）**。

| 用途 | 文案 |
|---|---|
| 核心宣言 | **冇人係廢物，只係未喺啱嘅光裡面被看見。** |
| Hero | **由廢到輝，唔需要等人批准。** |
| 選物主張 | 選一件令日常發光嘅嘢。 |
| 英文 | Nothing is wasted. Some things just need the right light. |
| 日文 | まだ光を見つけていないだけ。 |

**兩條底線**：①「廢」係未定形／暗，唔係破爛頹廢；② 廢佬係店嘅「聲音同眼光」，唔使每頁放佢個樣。

---

## 2. 品牌語氣

- 主語言繁中；口吻廣東話（「各位街坊」）；日文做主視覺標題、英文做國際資訊。
- **動詞用「選／揀／帶／放」，唔用「搶／爆／囤」**——買嘢係「選中」。
- **全站禁字**：搶購、爆款、限時、跳樓價、最後一件、瘋搶、必入、熱賣、人氣第一、庫存告急（「CP 值」改「值回票價」）。

## 3. 視覺系統（v2 已收斂）

### 顏色（一個光軸 + 功能色，唔再係多 accent）

| 角色 | 深底（黑曜石） | 淺底（米白）變體 | 說明 |
|---|---|---|---|
| 主背景 | 黑曜石 `#10100F` | — | 主舞台 |
| 閱讀／商品底 | — | 米白 `#F3F0E9` | 商品頁／結帳 |
| 夜色過渡 | 深靛藍 `#203047` | — | 只做夜色層，唔算 accent |
| **唯一光軸** | 琉璃青綠 `#65C8C2` | `#1F6F6A`（5.2:1） | 指引／reveal／選中 |
| **被選中閃現** | 琥珀金 `#E3AE5C` | `#8A5A1E`（5.2:1） | 只喺加購／收藏嗰一下 |
| 功能色 | 朱砂紅 `#C84A40` | `#A63B32`（5.6:1） | 售罄／警示／錯誤 |

- ❌ **刪除紫羅蘭 `#8B78D6`**（AI 站最愛紫藍嘅入口）。
- **鐵律**：青綠＝唯一光軸；琥珀金用得少先矜貴；底色要靜，光色先有力量。

### 字體（定死主從）

- **巨型 statement／標題 ＝ 思源宋體**（襯線、極細字重）。
- **功能字／價錢／規格 ＝ 思源黑體**。
- 唔用西式粗黑、唔用 `tracking-tight` 英文大寫做 statement。

### Motion（光嘅物理）

- **光＝ease-out、漸亮、reveal；唔用 springy bounce**（光係「滲出嚟」，唔係「彈出嚟」）。
- 商品卡 hover：一圈 1px 薄折射光邊（specular ring），**光由下而上 reveal**，唔用陰影放大／浮起。

### Liquid Glass（收緊）

- 只喺 nav／CTA／search／cart drawer／modal。
- **唔霧化商品相、唔半透明商品卡**。

## 4. 招牌動畫：廢 → 輝（光軸統一）

> 開場分鏡（3 秒一鏡）：黑曜石 →「廢」炭黑 →「广」屋頂掀開（光縫）→ 筆畫溶解 →「輝」＋光字旁滲青綠 glow → 光漫開成首屏 → `[入店][直接選購]`。

- **字形本身係故事**：「廢」＝「广」（遮蔽）＋「發」；「輝」＝「光」＋「軍」——「屋頂揭開，光滲出嚟」。兩字都 15 畫。
- **SVG 實現**，唔用重 3D；`feGaussianBlur` 只限 3 秒開場，光暈改 CSS `drop-shadow`。
- **光軸**：廢＝暗＝地下，輝＝光＝頂樓——morph 同「上樓」係**同一條軸**。

---

## 5. 虛擬店 THE HIRYU ROOM（垂直「上樓」）

| 層 | 區 | 光感 | 展示 |
|---|---|---|---|
| 地下 B1 | 未定形 | 黑／霧灰／微藍 | 新創作者、寄賣第一批 |
| 一樓 F1 | 光の棚 | 靛藍／青綠／琥珀折射 | 主力生活選物、禮物 |
| 頂樓 F2 | 輝琉之間 | 暖白／半透明琉璃 | 聯名、廢佬 Picks、Studio |

**互動 Bring It to Light**：hover（光邊＋品牌／品名／價）→ 點擊浮出→過折射層→變 2D 詳情卡 → 加購光點飛入袋 → 關閉返原位。

**⚠️ Scroll 語義（已解決）**：首頁 scroll＝「落店入地下」；真正「上樓」＝THE HIRYU ROOM 嘅 2.5D 垂直鏡頭（scroll 進度＝海拔，光愈高愈亮）。兩件事各自成立，唔好喺首頁做「向上 scroll」。

**MVP**：2.5D 用 CSS perspective + `translateZ` 視差（首屏零 WebGL）；「入店」先 `next/dynamic` lazy-load 3D；mobile 關反射、6→3 hotspot、窄屏降級 stacked list；無 WebGL／慢網自動切 2D。

## 6. 首頁分鏡（9 區，每區視覺＋互動）

1. **開場 morph**｜黑曜石＋廢→輝 morph＋青綠單光軸｜3 秒入首屏，雙入口（永遠有直選）。
2. **Hero statement**｜米白底、巨型明朝宣言＋微型功能字｜scroll 光帶由下 reveal。
3. **ROOM 預覽**｜黑曜石 2.5D 三層斷面（地下暗→頂樓暖白）｜hover 樓層亮、click 入店（3D lazy-load）。
4. **廢佬揀俾街坊**｜米白畫廊 70/30、細字標物料／產地／價｜card hover 光邊＋Raw/Shine。
5. **3 Collections**｜三張大圖各一束青綠／琥珀光｜click 入 collection，光跟主題。
6. **Makers in Light**｜黑白灰作品／半身肖像（非 logo 牆）｜hover 浮寄賣者一句話。
7. **廢佬講兩句**｜黑底聲波（聲線，唔出樣）｜click 播 30 秒＋文字版並排。
8. **Studio／Bring Your Work to Light**｜米白兩入口各一束光｜CTA hover 光邊。
9. **Footer 宣言**｜黑曜石底宣言＋英日小字｜scroll 到尾光收攏成 logo 光點、回頂。

## 7. 技術方案（v2 已收斂）

### Stack
Next.js（App Router）+ TypeScript + Tailwind + Framer Motion + zustand（cart）；3D 後補 React Three Fiber。

### 兩層架構（關鍵分層）
- **Commerce Core**（`lib/`：資料＋邏輯＋store）＋ **品牌體驗層**（`components/room/`：純展示），靠 `selectors.ts` 對接。日後換 R3F 只換 room 層，commerce 零改動。

### 目錄結構（Maco）
```text
app/  layout.tsx · page.tsx · room/page.tsx · shop/page.tsx · shop/[slug]/page.tsx · collections/[slug]/page.tsx
components/brand/    LogoMorph · Hero · Header · Footer
components/commerce/ ProductCard · ProductDetail · CartDrawer · SearchBar · FilterBar
components/room/     Room · Floor · ProductHotspot · BringToLightModal · RawShineSwitcher
components/ui/       GlassPanel · Button · Chip
lib/                 types.ts · store.ts(zustand) · selectors.ts
data/                products.json · collections.json · makers.json
```

### 數據模型（Maco）
```json
{ "id":"sku-007", "slug":"glass-paperweight-no7", "brand":"光る硝子工房",
  "name":"七号 手吹玻璃紙鎮", "price":{"currency":"HKD","amount":68},
  "material":["手吹玻璃","拉絲鋁"], "story":"…", "category":"光を纏う",
  "floor":"F1", "origin":"香港", "colors":["琉璃青","琥珀金"],
  "images":{"raw":"…","shine":"…"}, "position":{"x":0.35,"y":0.6,"z":0} }
```
`floor` enum＝`B1|F1|F2`；`position`（0–1 三軸）＝日後 R3F anchor；SKU 對應只靠 `id`。

### 效能預算（Codex，硬數字）
- LCP ≤2.5s ／ FCP ≤1.8s ／ CLS <0.1 ／ INP <200ms ／ 首屏 JS ≤170KB gzip。
- 動畫只准 `transform`＋`opacity`；圖片 AVIF 主 WebP fallback、Hero ≤150KB、除 LCP 外全 lazy。
- 對比度：見第 3 節淺底變體（青綠 `#1F6F6A`、琥珀 `#8A5A1E`、紅 `#A63B32`）。

### 無障礙
- `useReducedMotion()` 關 morph／飛光點；hotspot 做語意 `<button>`＋鍵盤 focus；`aria-live` 於袋數量／售罄；對比度 WCAG AA（已實測）。

### 安全（mock → 真電商前預留）
- `.env` 不入 git；`NEXT_PUBLIC_` 只放公開 key；`pnpm audit`＋lockfile＋Dependabot；zod server-side 驗證；CSP `script-src 'self'`；Stripe token 化（卡號唔經自己 server）；VPS 加固（UFW／fail2ban／key-only SSH／HSTS）。

### SEO
- 2D 商品頁 SSG/SSR（先俾 Google 收錄）；2.5D 房只做體驗入口。
- 每頁 title＋description＋OG＋canonical；JSON-LD（Organization／Product+Offer／BreadcrumbList）；sitemap＋robots；圖片 alt＋尺寸。

### Build order（Maco）
1. Scaffold（Next+Tailwind+framer+思源字體+色 token）
2. data + types + zustand（資料層行先）
3. Header+Hero+LogoMorph（首頁最快見光）
4. ProductCard+shop+詳情+CartDrawer（2D 商務＝直接選購 fallback）
5. room 五件套 → 6. Raw/Shine＋飛光點＋reduced-motion 打磨

## 8. 五條審美 DNA（v2 修正）

1. **黑白灰做容器**——色彩同材質全留俾「選物」。
2. **極端字體層級**——巨型思源宋體 statement vs 微型思源黑體功能字。
3. **單一光軸（琉璃青綠）＋ 琥珀金「被選中」閃現**——唔用多 accent、唔用螢光、冇紫藍。
4. **「廢 → 輝」morph signature**——光揭開屋頂，字發光。
5. **垂直「上樓」敘事**——由暗到光、由低到高、由廢到輝。

**底層同一件事**：*「用頂級規格，展示平凡嘅嘢。」*
