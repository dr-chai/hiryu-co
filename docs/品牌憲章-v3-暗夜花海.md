## 一、一句品牌宣言

> **輝琉 Hiryu — 廢而不頹，碎而有光。**
> 在失速、疲倦與不完美之中，仍然保留一點會折射的自己。

補充宣言（可做 slogan 輪播／子頁面）：

- 「沒有盛開，都可以有光。」
- 「將頹廢封進琉璃，留住一點不肯熄滅的光。」
- 「裂痕不是失敗，是光進來的地方。」

## 二、美學命名（自創分類，唔用「和風暗黑哥特」）

避免「和風暗黑哥特」呢個標籤（偏動漫／二次元周邊店）。建立自己專屬美學分類：

- **「輝」＝ 微光、霓虹、反射**
- **「琉」＝ 琉璃、流動、留住**

> Logo 同成個網站圍繞「**一束被藤蔓包住、但仍然透光的碎裂琉璃**」。

## 三、美學方向（四支柱）

**港風頹廢感 × 和風幽玄 × 琉璃新藝術 × 暗夜花海**

「輝琉 Hiryu」唔係普通日系暗黑店，而係一個**帶少少香港霓虹、帶少少地獄少女式寂靜、但最後仍然有光嘅世界**——廢唔等於熄滅，而係將裂縫變成會反光嘅琉璃。

## 四、三個美學支點（詳解）

### 1. 和風幽玄（朦朧、深不可測、留白情緒）
- 深藍黑、紫黑、酒紅背景像深夜庭園／舞台帷幕。
- 垂墜花藤與隱約浮出嘅花影，像夜色裡看不盡嘅庭園深處。
- 畫面**唔將一切交代清楚**，令觀者感覺「黑暗後面仲有更大嘅世界」。
- 中央大面積暗處像「未被命名嘅入口」，水面與兩側花藤只提供極少量引導。

### 2. 琉璃新藝術（折射、流動、半透明生命感）
- 琉璃唔止係玻璃，而係**折射／流動／半透明生命感**嘅材質設定。
- 新藝術＝植物線條嘅**有機纏繞**。
- 水面像液態玻璃、玉石、冰層與蛋白石嘅混合物，**冇硬邊界**。
- 金色／半透明枝蔓以曲線延伸（新藝術常見嘅植物性、裝飾性線條）。
- 花朵非寫實靜物，而像**封存在玻璃中／從琉璃深處透出嘅花魂**。

### 3. 暗夜花海（最重要嘅情緒骨架）
- 花唔係白天盛放，而係**喺黑暗裡自己發光**。
- 花海密度高，牆面、背景、藤蔓與水面反射全被植物包覆 → **包圍感**（被帶進密林深處，唔係站外面欣賞）。
- 局部高光從花瓣、水波、霧氣、透明材質滲出 → 「黑暗中仍有生命呼吸」。
- 紅色版 = 熱烈／危險／魅惑；藍紫版 = 寧靜／靈性／療癒。

## 五、空間設定（琉璃花庭）

> 這是一座只在夜裡出現的琉璃花庭。
> 花藤自幽暗處垂落，萬千花影在鏡面水境中無限蔓延；真實與倒影、花瓣與光、深夜與夢境交疊成沒有盡頭的空間。
> 黑暗並不吞沒生命，反而讓每一點微光、每一瓣半透明的花，都顯得更加溫柔而鮮活。

**參考圖轉譯做網站語言嘅三件事（唔止「花＋黑底」）：**
1. **密集花海嘅包圍感**（唔係裝飾，係空間）
2. **鏡面延伸嘅無邊界感**（mirror / 無限反射）
3. **黑暗裡一點發光嘅生命感**（局部高光／透光材質）

沉浸式櫻花／鏡面空間 = 「無盡花境」空間參考；彩繪玻璃 + 新藝術藤蔓 = 網站嘅**線條骨架**。

## 六、配色使用原則（非簡單 hex，而係「用色紀律」）

| 角色 | 原則 | 用途 |
|---|---|---|
| **黑** | 唔係純黑一種：墨黑、黑紅、深啡黑**混用** | 畫面深度、背景 |
| **紅** | 情緒焦點 | 按鈕、花心、裂紋滲光、限量標籤；**唔好鋪大面積正文背景** |
| **白** | 係「琉璃反光」，唔係辦公室白底 | 用偏暖**骨瓷白**，避免 `#FFFFFF` 大面積 |
| **金** | 只佔好少：舊金（古董金屬／香爐／舊招牌金漆／金繕裂縫） | 唔似婚禮金／暴發戶金 |

## 九、待轉譯做網站語言（research 方向）

1. **配色 → 精確 token**：墨黑／黑紅／深啡黑／骨瓷白／舊金／深紅（各出 hex + 對比度驗證）。
2. **字體 → 幽玄 × 新藝術感**：襯線／細字重做 display，點樣配「藤蔓線條骨架」。
3. **動效 → 技術**：鏡面無限反射、琉璃折射（refraction）、花海粒子／shader、新藝術 SVG 線條描邊。
4. **參考站 → 拆解**：awwwards／godly 嘅暗夜沉浸、鏡面、彩繪玻璃、新藝術線條案例。
5. **Hero → 結構**：「無邊界花海」首屏點樣落地（沉浸式花卉投影 + 鏡面反射 + 藍紅對撞）。
