## 一、SHIFTBRAIN（shiftbrain.com）＝「白畫廊」

日本頂級數碼設計工作室。風格：**現代日系極簡 × White Cube 白立方展覽空間**。

### 特點
- UI 純黑白灰、零裝飾，成個畫面交俾「作品／內容」。
- **超大字 × 極細字重**（Light/Thin），高級感靠「尺度對比」唔靠粗黑。
- 非對稱 70/30 佈局：左巨型 statement，右垂直分類 filter（有「目錄」編輯感）。
- 卡片內嵌 capsule switcher（`TEXT / VISUAL / HUMAN`）——卡片有數碼可玩性。

### 借咩（改寫成 HIRYU）
1. **白／米灰極簡底**做 UI 骨架 → 突顯「日常選物」質感（由廢到輝）。
2. **極細大字 × 雙語排版** → 標題用洗練明體，小字標物料／產地／親民價。
3. **卡片內切換掣** → HIRYU 版 `[原態 Raw / 輝光 Shine]`，hover 見到「由廢到輝」蛻變。

### 唔借
- 唔好做到太冷／太乾淨，失去「廢佬」嘅街坊溫度。

## 二、HUGE（hugeinc.com）＝「黑舞台」

全球頂級 agency。風格：**暗黑前衛 × Digital Brutalism × 巨型 typography**。

### 特點
- 純黑背景 + 單一 accent 色（螢光洋紅）。
- 3D 雕塑（「H」）做主視覺，用「平民材質」（矽膠、鋁箔邊）但頂級 3D 光線打磨 → 變數碼藝術品。
- 巨型字、超緊字距、字即係圖（Typography as Image）。
- 90% 中性灰階 + 10% accent 色；文字有失焦／疊層質感。

### 借咩（改寫成 HIRYU）
1. **黑底舞台** → HIRYU 開場／THE HIRYU ROOM 用（沉浸、有魔法）。
2. **頂級規格展示平凡嘢** → 用高質光影展示幾十蚊好物，「可負擔但超值」嘅反差係殺手鐧。
3. **巨型 typography + 單一 accent** → 但 HIRYU 唔用螢光洋紅，改**琉璃青綠／琥珀金**；字用東方字體唔用西式粗黑。

### 唔借
- 唔好成個站都黑底（會令商品瀏覽／結帳辛苦）；唔好用 cyberpunk／螢光霓虹。

## 四、共同審美結論

兩個參考網站一白一黑、一極簡一前衛，但底層同一件事：

> **「用頂級規格，展示平凡嘅嘢。」**

高級感 ≠ 貴，而係「你點樣對待一件平凡嘢」——呢個同 HIRYU「由廢到輝」完全一致：廢（平凡、未見光）→ 輝（被好好咁展示、被選中、發光）。
