## 一、UI Copy 標準

**通用鐵律**：繁中主、廣東話口吻；日文做主視覺／標題裝飾、英文做國際資訊。動詞用「選／揀／帶／放」，**唔用「搶／爆／囤」**——買嘢係「選中」一件嘢，唔係「搶」一件嘢。句末落「光」意象，但唔堆砌。

**全站禁字**：搶購、爆款、限時、跳樓價、最後一件、手快有手慢冇、瘋搶、必入、熱賣、人氣第一、庫存告急、CP 值（改用「值回票價」）。

| 區塊 | 點寫 | 現成文案 | 禁字 |
|---|---|---|---|
| **Hero** | 一句巨型 statement + 一句引導；唔落價錢／折扣 | 主句「由廢到輝，唔需要等人批准。」副句「各位街坊，揀一件令日常發光嘅嘢。」按鈕 `[入店]` `[直接選購]` | 立即搶購、開賣 |
| **商品卡** | 品牌／品名／價錢 + 一句「廢佬式選物語」（唔係規格文） | 「〔品名〕——〔一句點樣令日常發光〕」（見示範） | 熱賣、人氣第一 |
| **商品頁** | 開頭一句選物語 → 先規格（物料／產地／尺寸／價錢） | 加購按鈕 `[帶到光裡]`；價錢旁可註「親民價」 | 庫存告急、限量 |
| **購物袋** | 輕鬆、唔施壓；免運提示寫得溫柔 | 「仲爭少少就送到你手上，要唔要揀多件？」按鈕 `[去結帳]` | 立即結帳（用「去結帳」） |
| **結帳** | 樸素、可信、快 | 標題「帶佢哋返屋企」；成功見示範 | 優惠倒數、秒殺 |
| **寄賣申請** | 邀約語氣，強調「被選中」唔係「上架賺錢」 | 標題「Bring Your Work to Light」副句「將你嘅嘢帶到光裡，等啱嘅人睇到。」 | 招商、變現 |
| **Footer** | 宣言做收尾（繁＋英＋日） | 「冇人係廢物，只係未喺啱嘅光裡面被看見。」／ Nothing is wasted. Some things just need the right light.／まだ光を見つけていないだけ。 | — |
| **錯誤／空狀態** | 廢佬口吻自嘲＋安慰，唔冷冰冰 | 404「呢個位仲係暗嘅，未上架。返去光嗰邊睇下？」搜尋無結果「搵唔到。可能佢仲等緊被帶到光裡，換個字試下？」 | 系統錯誤、請稍後再試 |

## 二、docs/ 文檔結構（單一真源）

```
docs/
  00-品牌憲章.md            # 唯一真源：定位／語氣／視覺／IA（已有，改名加編號）
  01-ui-copy標準.md         # 呢份：文案＋禁字（Sheila 出品）
  02-命名規範.md            # 代碼／分支／commit 慣例（見下）
  03-參考網站分析.md         # 設計參考（已有）
  04-API與資料模型.md        # 商品 schema、collection、寄賣資料欄位
  05-進度記錄.md             # 每週決策 log，開頭寫日期＋拍板人
```

**維護規則**：① 全部繁體中文、檔名 `NN-短名.md`（NN 排序）；② 憲章 = 唯一真源，改嘢先改憲章再同步下游；③ 重大決定寫入 `05-進度記錄.md` 一行 log；④ 唔同 agent 各寫各檔，**唔好兩個檔寫同一樣嘢**。

## 三、code 命名慣例

- **組件（PascalCase，跟「光」語意）**：`HeroRoom`、`ProductCard`、`BringToLight`（加購轉場）、`CartDrawer`、`MakersInLight`、`FooterManifesto`、`EmptyState`。
- **變數（camelCase）**：`productTitle`、`price`、`makerName`、`isInLight`、`collectionSlug`。
- **collection slug（kebab-case，跟憲章 IA）**：`wear-the-light`、`rooms-with-light`、`everyday-margin`。
- **分支**：`feat/hero-morph`、`feat/bring-to-light`、`fix/cart-drawer-empty`。
- **commit（Conventional Commits 前綴 + 廣東話語義）**：
  - `feat: 商品卡加「帶到光裡」轉場`
  - `fix: 購物袋空狀態照返廢佬口吻`
  - `style: 標題轉洗練明朝體`
