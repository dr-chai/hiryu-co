```css
:root {

  --cold: #0C1020;         /* 冷端青黑過渡 */

  --violet: #845EC2;       /* 紫晶透光（裝飾／大字） */
  --violet-text: #B39DDB;  /* ⚠️ 透光紫（紫字正文專用，WCAG 8.22） */
  --cyan: #00B4D8;         /* 琉璃青藍焦散 */

  /* 次（紅，極少點綴） */

  /* 白 + 金 */

  --gold-antique: #B08A3E; /* 舊金實體（古董金屬） */

```

> ⚠️ **WCAG 關鍵**：紫晶 `#845EC2` on 黑 = 4.09（正文唔過 AA）→ 紫字正文一定要用透光版 `#B39DDB`（8.22）。金只准放黑底（金 on 骨白全 FAIL）。禁用 `#FFD700`／`#D4AF37`（暴發戶金）。

## 六、5 大特效落地順序（最少成本最大衝擊）

| # | 特效 | 主力實現 | 進階 |
|---|---|---|---|
| 1 | 金絲線條 | SVG + Motion `pathLength`（近零成本） | drei `<Line>`/`TubeGeometry` |
| 2 | 水面焦散 | SVG `feTurbulence`+`feDisplacementMap`（#00B4D8） | drei `<Caustics>` |
| 3 | 琉璃折射 | `backdrop-filter` glassmorphism + `feOffset` 色散 | `MeshTransmissionMaterial` |
| 4 | 花海粒子 | CSS/Canvas 2D / Motion | `InstancedMesh` + shader sway |
| 5 | 鏡面反射 | CSS `scaleY(-1)` 倒影 | drei `MeshReflectorMaterial` |

> 「幽玄」統一關鍵一招：全站後製疊 `Vignette` + 極細 `ChromaticAberration`（#845EC2/#00B4D8）+ `Noise`(film grain)。

## 七、工具鏈關鍵

- **React 3D**：`@react-three/fiber@9`（**React 19 必 @9，@8 只配 18**）+ drei（`MeshTransmissionMaterial`/`Caustics`/`Sparkles`/`Environment`）+ `@react-three/postprocessing`。
