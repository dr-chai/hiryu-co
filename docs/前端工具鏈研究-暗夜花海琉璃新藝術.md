# 前端工具鏈研究報告 — HIRYU「暗夜花海 × 琉璃新藝術 × 幽玄」

> 對象技術棧：**Next.js 16 + React 19 + Tailwind CSS 4 + Motion**
> 視覺目標：鏡面反射、玻璃折射、焦散（caustics）、花海粒子、新藝術（Art Nouveau）線條、幽玄氛圍。
> 標記：✅ = 免費開源可直接用；💳 = 要 key／付費（但核心通常有免費層）。

## 0. 基線版本相容（先睇呢個，否則會裝錯版本）

| 套件 | React 18 | React 19 |
|---|---|---|
| `@react-three/fiber` | `@8` | `@9` |
| `motion`（前身 `framer-motion`） | ✅ | ✅（`import { motion } from "motion/react"`）|
| `@react-three/drei` | ✅ | ✅（跟 fiber 版本）|

**關鍵坑**：R3F 係 React renderer，必須配對 major version —— `@react-three/fiber@8` 只配 React 18，`@react-three/fiber@9` 先配 React 19。你哋用 Next.js 16（內建 React 19），**一定要裝 `@9`**。
來源：[R3F Installation](https://r3f.docs.pmnd.rs/getting-started/installation)、[@react-three/fiber npm](https://www.npmjs.com/package/@react-three/fiber)

## 1. React 3D（WebGL / R3F 全家桶）

### 1.1 three（Three.js）
- **npm**：`three` · **repo**：https://github.com/mrdoob/three.js
- **用途**：底層 WebGL 引擎，所有 3D 嘅地基。
- **裝**：`npm install three`
- **授權**：✅ MIT 免費。

### 1.2 @react-three/fiber
- **npm**：`@react-three/fiber` · **repo**：https://github.com/pmndrs/react-three-fiber
- **用途**：Three.js 嘅 React 渲染器（用 JSX 寫 3D 場景，聲明式）。
- **裝（React 19 / Next 16 一定要 @9）**：
  ```bash
  npm install three @react-three/fiber@9
  ```
- **授權**：✅ MIT 免費。

### 1.3 @react-three/drei
- **npm**：`@react-three/drei` · **repo**：https://github.com/pmndrs/drei
- **用途**：R3F 嘅「工具箱」，成堆即用 helper／material／粒子。
- **裝**：`npm install @react-three/drei`
- **授權**：✅ MIT 免費。
- **同呢個 project 直接相關嘅現成組件**：
  - `MeshTransmissionMaterial` —— **玻璃折射**（transmission + chromatic aberration + 模糊），琉璃新藝術主力。文檔：https://drei.docs.pmnd.rs/shaders/mesh-transmission-material
  - `Caustics` —— **焦散光**（光穿過透明面投影落地面，基於 ray-marching）。文檔：https://drei.docs.pmnd.rs/staging/caustics
  - `Sparkles` / `Stars` —— **花海粒子／星光**（glitter 粒子、星野）。
  - `Environment` + `Lightformer` —— **鏡面反射**（環境貼圖，令玻璃/金屬有反射高光）。
  - `Line` / `Trail` / `Svg` —— **新藝術線條**（3D 曲線、軌跡、SVG 路徑轉 3D）。
  - `Instances` / `Instance` —— 大量花（成千上萬個體）高效渲染。
  - `Float` / `Text` / `ContactShadows` —— 漂浮動效、3D 文字、接觸陰影。

### 1.4 @react-three/postprocessing（+ postprocessing）
- **npm**：`@react-three/postprocessing` + `postprocessing` · **repo**：https://github.com/pmndrs/react-postprocessing
- **用途**：GPU 後製特效（bloom、chromatic aberration、depth of field、vignette、noise）—— 幽玄「發光／色散」氛圍靠佢。
- **裝**：
  ```bash
  npm install @react-three/postprocessing postprocessing
  ```
- **用法**：`<EffectComposer>` 包住 `<Bloom>` `<ChromaticAberration>` 等。
- **授權**：✅ MIT 免費。
- 文檔：https://react-postprocessing.docs.pmnd.rs/effects/bloom

### 1.5 Next.js 16 接入要點
Next.js 通常 out-of-the-box 行到，但 Three.js 生態有啲 package 未 transpile 時要加：
```js
// next.config.js
module.exports = {
  transpilePackages: ['three'],
}
```
來源：[R3F Installation](https://r3f.docs.pmnd.rs/getting-started/installation)

## 2. 動畫／UI 組件庫

### 2.1 Motion（前身 framer-motion）—— 你哋已用緊
- **npm**：`motion`（舊名 `framer-motion`） · **repo**：https://github.com/motiondivision/motion
- **用途**：React 動畫核心（layout animation、SVG path draw、手勢、scroll）。
- **裝**：`npm install motion`，`import { motion } from "motion/react"`
- **SVG 線條繪製**（新藝術線條動畫）：`motion.path` + `pathLength` 做「畫出嚟」效果。
- **授權**：✅ MIT 免費（開源核心）。
- 文檔：https://motion.dev/docs/react

### 2.2 Magic UI
- **repo**：https://github.com/magicuidesign/magicui · **網站**：https://magicui.design/
- **用途**：150+ 免費動畫組件（marquee、dock、particles、confetti、border beam、globe、animated-list 等），shadcn/ui 嘅「最佳拍檔」。
- **裝**（shadcn registry 方式）：
  ```bash
  npx shadcn@latest add @magicui/particles        # 粒子
  npx shadcn@latest add @magicui/border-beam      # 光掃邊
  npx shadcn@latest add @magicui/animated-list
  ```
- **授權**：✅ MIT 免費開源。（另有 Magic UI Pro = 付費 blocks）
- 組件一覽：https://magicui.design/docs/components

### 2.3 Aceternity UI
- **網站**：https://ui.aceternity.com/components · **文檔**：https://ui.aceternity.com/docs
- **用途**：200+ 免費 React + Tailwind + Motion 組件，多「神級」背景／光效。
- **裝**：
  ```bash
  npx aceternity-ui init
  npx aceternity-ui add <component>
  ```
- **相關現成組件**：`Vortex`（粒子渦旋背景）、`AuroraBackground`（極光）、`Lamp`（聚光燈）、`Spotlight`、`WavyBackground`、`Sparkles`。
- **授權**：✅ 核心組件免費（copy-paste）；💳 Aceternity UI **Pro**（premium blocks）要付費。

### 2.4 GSAP
- **npm**：`gsap` + `@gsap/react` · **repo**：https://github.com/greensock/GSAP
- **用途**：業界最強 timeline／scroll 動畫引擎，適合複雜「上樓 scroll 敘事」。
- **裝**：
  ```bash
  npm install gsap @gsap/react
  ```
  ```js
  import gsap from "gsap";
  import { useGSAP } from "@gsap/react";
  import { ScrollTrigger } from "gsap/ScrollTrigger";
  gsap.registerPlugin(useGSAP, ScrollTrigger);
  ```
- **授權**：✅ **免費**（2024 年被 Webflow 收購後，所有 plugin 含 ScrollTrigger／SplitText 全部免費，核心 MIT）。
- 文檔：https://gsap.com/resources/React/ · https://gsap.com/docs/v3/Installation/

### 2.5 shadcn/ui（底層組件系統）
- **repo**：https://github.com/shadcn-ui/ui
- **用途**：Radix + Tailwind 嘅可複製組件底座，Magic UI／Aceternity 都建喺佢上面。
- **裝**：`npx shadcn@latest init`
- **授權**：✅ MIT 免費。

## 4. MCP skill（畀 coding agent 用）

> ⚠️ 重要澄清：市面上叫「MotionMCP」嘅嘢有兩個，好易撈亂：
> ① **Motion.dev AI Kit**（即 framer-motion 嗰個 Motion 嘅官方 MCP）—— 呢個先係你要嘅；
> ② 一堆「Motion MCP」其實係 **usemotion.com 任務管理 SaaS** 嘅第三方 server —— 同動畫完全冇關係，唔好裝錯。

### 4.1 Motion AI Kit（官方，framer-motion/Motion 的 MCP）⭐ 最推薦
- **裝**：`npx motion-ai`
- **用途**：俾 Claude Code／Cursor／Gemini CLI 等搜最新 Motion 文檔＋範例 metadata。

### 4.2 Magic UI MCP（官方）
- **repo**：https://github.com/magicuidesign/mcp · **CLI**：https://github.com/magicuidesign/cli

### 4.6 點裝入 OpenClaw（`~/.openclaw/openclaw.json`）

## 5. 字體／圖片優化

### 5.1 next/font（Next.js 內建）
- **用途**：自動 self-host + 優化字體（Google Fonts + 本地），消除外部字體請求、零 layout shift。
- **裝**：**毋須裝**（Next.js 內建）。
  ```tsx
  import { Noto_Serif_SC } from "next/font/google";          // 思源宋體（Google 有 Noto Serif SC）
  // 或本地 .woff2：
  import localFont from "next/font/local";
  ```
- **授權**：✅ 免費（Next.js 內建）。
- 文檔：https://nextjs.org/docs/app/getting-started/fonts

### 5.2 fonttools / pyftsubset（CJK 字體瘦身 —— 思源宋體必用）
- **pip**：`fonttools`（含 `pyftsubset`） · **repo**：https://github.com/fonttools/fonttools
- **用途**：思源宋體／Noto Serif CJK 動輒 10–20MB，**一定要 subset** 只留用到嘅字 → 幾百 KB。
- **裝**：
  ```bash
  pip install fonttools brotli
  ```
- **用**（按字集 subset 成 woff2）：
  ```bash
  pyftsubset NotoSerifSC-Regular.otf \
    --unicodes="U+4E00-9FFF,U+3000-303F,U+0020-007E" \
    --layout-features='*' --flavor=woff2 \
    --output-file=NotoSerifSC-sub.woff2
  ```
- **授權**：✅ MIT 免費。
- 文檔：https://fonttools.readthedocs.io/en/stable/subset/

### 5.3 sharp（圖片優化，AVIF/WebP）
- **npm**：`sharp` · **repo**：https://github.com/lovell/sharp
- **用途**：Next.js 預設用 sharp 做 `next/image` 伺服端 resize／轉 AVIF/WebP；亦可獨立用嚟批量壓 product 相。
- **裝**：Next.js 16 通常**已內建**，獨立用先 `npm install sharp`。
- **授權**：✅ Apache-2.0 免費。
- 文檔：https://sharp.pixelplumbing.com/
