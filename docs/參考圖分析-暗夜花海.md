## 二、配色提取（真圖 hex）

### 黑底層次
- `#080B10` 玄青黑（帶微冷藍調，比純黑有空氣感）
- `#12090D` 焦炭深紫黑（帶酒紅基底嘅暗部）

### 紅色系（赤熱 / 殉道）
- `#FF2A4D` 緋紅高光（透光發光核心）
- `#E63946` 緋紅（次一級）
- `#8B1E3F` 沉香酒紅、`#4A0E17` 深波爾多（暗部花瓣/水影沉積）

### 藍紫系（幽玄 / 深海）
- `#845EC2` 紫晶透光、`#6C5CE7` 水晶紫（花瓣與色散邊緣）
- `#00B4D8` 琉璃青藍、`#2C7DA0` 深青（水下焦散 caustics）
- `#1E2749` 夜幕青紺（過渡漸變）

### 金屬 / 點綴（光之碎片）
- `#E2C076` 新藝術金絲、`#F3E5AB` 冷調香檳金（Art Nouveau filigree）

### 骨白 / 高光
- `#F7F4EA` 琉璃骨白（微暖、次表面散射質感）

### 紅版 vs 藍紫版（兩個 mood）
- **紅色版**：破壞性熱情／涅槃——高張力、慾望、破壞後重生（戲劇性）。
- **藍紫版**：幽玄靜止——內斂清冷、哲學寂靜、超現實安全感（空靈 Wabi-sabi）。

## 三、材質（Materiality）

- **琉璃 / 晶體**：**次表面散射（SSS）**——邊緣唔死硬，內部吸光再柔和透出（半透明玉質感）；**色散（chromatic aberration）**——邊緣帶三稜鏡彩虹邊，強化「碎裂」。
- **水面焦散**：底部有機網狀流體 **caustics**，模擬光穿過流動水體聚焦嘅高動態光紋。
- **鏡面反射**：地面非 100% 鏡面，帶 **菲涅爾（Fresnel）**——越平視反射越強、垂直睇透入深底。
- **金絲游線（Kintsugi filigree）**：琉璃邊緣包極細金絲，呼應「碎而有光」＝金繼工藝。

## 四、構圖（Composition）

- **去中心化 + C-curve 包圍場域**：冇單一霸道主體，靠「前景有機琉璃 + 中景流動焦散 + 背景垂掛夜藤」成半弧形包圍。
- **無限鏡面延伸**：地平線壓低／消隱於黑暗，空間向上下無限鏡像延伸（失重、漂浮）。
- **實體留白**：上方留 40–50% 墨色虛空，同下方繁複流體光影成「極簡 vs 極繁」張力。

## 五、光影（Lighting）

- **由內自發光（bioluminescence）**：光唔係頂部照落，而係藏喺琉璃內部／水底滲出。
- **局部滲光（volumetric glow）**：高光邊緣伴微微霧化光暈（bloom），玻璃多一層呼吸感。
- **高對比邊緣輪廓光（rim light）**：暗部極深，物體邊緣被極細極亮金/青輪廓光勾勒＝「黑暗裡發光嘅生命感」。

## 六、轉譯做網站（工程級）

### 配色 Token（Tailwind 4 @theme）
```css
@theme {
  --color-bg-deep: #080b10;       /* 玄青黑 */
  --color-bg-surface: #0f141d;
  --color-gold-filigree: #e2c076;  /* 新藝術金絲 */
  --color-crimson-core: #ff2a4d;   /* 緋紅核心 */
  --color-violet-core: #845ec2;    /* 紫晶透光 */
  --color-cyan-caustic: #00e5ff;   /* 水下焦散 */
  --color-text-bone: #f7f4ea;      /* 琉璃骨白 */
  --color-text-muted: #8e95a5;
}
```

### Hero 構圖（深度分層）
1. **Backdrop**：`#080b10` 純暗底 + 漂浮暗夜藤蔓 SVG / 霧氣粒子。
2. **Center Stage**：3D 主題物懸浮於透明琉璃台，帶內部自發光。
3. **Foreground Base**：底部 30vh 實時動態焦散水面（Canvas WebGL），鏡像倒影 Hero 內容 = 無底深淵。
4. **UI 排版**：日式高級雜誌佈局，導航/標語分散四角（corner-anchored），中央留白俾光影呼吸。

### 動效
- **水面焦散**：自訂 fragment shader 運算有機 caustics；hover 微水波漣漪。
- **毛玻璃 2.0**：`backdrop-blur-md bg-white/[0.03] border border-gold-filigree/20`，hover 出動態彩虹色散邊框。
- **新藝術金絲描邊**：SVG path `pathLength: [0,1]` + `ease: [0.16,1,0.3,1]` 自然生長。

### 字體
- **大標題／品牌**：`Cormorant Garamond` / `PP Editorial New`（Ultralight/Italic，tracking 0.25em）+ 思源宋體 Light 300（中文）。
- **正文／UI**：`PP Neue Montreal` / `Inter Tight`（300/400，冷靜黑體）。

### 對標參考站
1. **Cartier Nature Sauvage / Chanel High Jewelry** — 黑色空間 + 珠寶琉璃 SSS + 光束掃射。
2. **Apple Vision Pro Landing** — 有機玻璃質感、菲涅爾光感、流體擬態。

## 七、一句總結（視覺精髓）

**「破裂不是終結，折射才是核心」**——將碎片當透鏡：暗黑＝「廢」，光穿過破碎琉璃爆出色散 + 金絲＝「碎而有光」。用 80% 純粹深淵黑襯 20% 琉璃內核極致高光，達頂級奢侈品水準。
