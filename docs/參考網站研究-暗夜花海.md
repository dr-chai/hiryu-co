# HIRYU 參考網站研究 — 暗夜花海 × 琉璃新藝術（v3 視覺改版 research）

> 由 Deep（DSH web search + web_fetch）整理。美學方向：**港風頹廢感 × 和風幽玄 × 琉璃新藝術 × 暗夜花海**，宣言「廢而不頹，碎而有光」。
> 每項＝**站名 + URL + 一句「借咩」**（對應 v3 配色 token／字體／5 大特效）。URL 全部實測存在；部分奢侈品站對 raw fetch 有 bot 防護（Cloudflare/Akamai 403），真人／ego-browser 開到。
>
> 對照 v3 token（`視覺spec-暗夜花海.md`）：`--ink #080B10`／`--plum #12090D`／`--crimson #FF2A4D`／`--violet #845EC2`／`--cyan #00B4D8`／`--bone #F7F4EA`／`--gold #E2C076`。

## 1. 暗黑花卉／沉浸式植物（dark floral immersive）

- **Diptyque Paris** — https://www.diptyqueparis.com
  借：燭光式 **rim light**（光源藏喺物體後方透出＝我哋「bioluminescence 由內自發光」嘅直接示範）+ 純暗底 + 單一商品 spotlight 構圖 + 編輯式 serif 留白。
- **Ann Demeulemeester** — https://www.anndemeulemeester.com
  借：**純黑底 + 花卉剪影 + 極端字級差**（主標 6–8× 正文）+ 詩意負空間——「港風頹廢 × 幽玄」嘅 fashion 轉譯範本。
- **Maison Margiela** — https://www.maisonmargiela.com
  借：**灰黑中性底 + 解構／未完成裸露邊緣**（「廢而不頹」個「廢」字嘅高級演繹）+ 低飽和材質，唔用純黑。
- **Erdem** — https://www.erdem.com
  借：**暗底深色花卉印花／深色花卉攝影**——「暗夜花海」喺服裝電商嘅成熟做法（構圖：花做底、人做焦點）。

## 2. 琉璃／彩繪玻璃／Art Nouveau 線條

- **Lalique（萊儷）** — https://www.lalique.com
  借：**琉璃水晶材質 + Art Nouveau 藤蔓 filigree 線條 + 黑金配色**——René Lalique 就係 Art Nouveau 琉璃宗師，呢個站係「琉璃新藝術」字面正源，`--gold #E2C076` 金絲線條直接對標。
- **Van Cleef & Arpels（梵克雅寶）** — https://www.vancleefarpels.com
  借：**自然花卉母題 + 珠寶 SSS 透光光澤 + 夢幻詩意敘事構圖**——「暗夜花海 × 珠寶光」嘅最佳混血範本（Art Nouveau 花枝線條係佢招牌）。
- **Baccarat（巴卡拉）** — https://www.baccarat.com
  借：**水晶折射 + 深紅水晶 accent（Rouge 540）+ 黑色空間**——緋紅 `#FF2A4D` 做暗底焦點色嘅同款打法。

## 3. 鏡面／無限反射／折射（reflection/refraction）

- **Swarovski（施華洛世奇）** — https://www.swarovski.com
  借：**稜鏡折射焦散（caustics）+ 多面反光 + 彩虹色散動效**——「碎而有光」落網頁嘅最佳技術示範（spec §七「琉璃折射／色散」直接對標）。
- **Lusion** — https://lusion.co
  借：**WebGL 玻璃折射 shader + 焦散光斑 + 流體模擬**——spec 進階版（`MeshPhysicalMaterial { transmission, ior, thickness }`、caustics shader）嘅現成代碼標杆，可直接扒技術。
- **Louis Vuitton** — https://www.louisvuitton.com
  借：**鏡面無限反射空間感**（Yayoi Kusama 無限鏡屋 campaign 語言）+ 高奢材質光感——spec §四「無限鏡面延伸」嘅品牌化示範。
- **Bruno Simon** — https://bruno-simon.com
  借：**WebGL 3D 沉浸 + 精準物理光影**（反射／折射／GI）——做「碎裂琉璃 Center Stage」主物件嘅技術天花板參考。

## 4. 幽玄／日式暗黑 wabi-sabi

- **Aesop** — https://www.aesop.com
  借：**剋制字體層級 + 大量留白（間 ma）+ 材質紋理 + 緩慢淡入動效**——「幽玄」嘅剋制感，spec §五字體層級直接對標。
- **Kokoro** — https://kokoro.co
  借：**日式幽玄靜寂 + 文化資產敘事 + 暗色剋制排版**（站名＝「心」）——「靜止嘅幽玄」落地成暗色 editorial 嘅現成範本。
- **Aman（安縵）** — https://www.aman.com
  借：**深暗空間 + 單一 focal point + 超慢動效**——「幽玄＝靜」嘅高端 hospitality 演繹（對應 spec §六「中央留白俾光影呼吸」）。
- **Issey Miyake（三宅一生）** — https://www.isseymiyake.com
  借：**幽玄氛圍 + 日式極簡 + 抽象剪影（摺／光與影）**——「由內發光 × 褶皺材質」嘅日本正源。

## 5. 奢華暗黑（珠寶／美妝／時尚，黑色空間 + 材質光感）

- **Cartier（卡地亞）** — https://www.cartier.com
  借：**黑空間沉浸 + 高級 scroll 動效 + 奢華字體層級**（CSSDA WOTY 2024 #3、Best UI）——luxury 暗黑網頁嘅黃金標杆，我哋 hero 改版直接對標。
- **Bottega Veneta（葆蝶家）** — https://www.bottegaveneta.com
  借：**啞光黑 + 極簡 + 材質質感（皮革編織紋理轉譯做琉璃紋理）**——「luxury = 空間 + 材質」而非裝飾。
- **Tom Ford** — https://www.tomford.com
  借：**黑金配色 + 光澤質感 + 戲劇性單側光影**——「黑色空間 + 材質光感」嘅美妝/時尚正源。
- **Immersive Garden** — https://immersive-g.com
  借：**沉浸式 scroll + 氛圍動效 + 高工藝感**（Awwwards SOTD 2024 / SOTM 2025）——agency 站做「沉浸敘事」嘅工程示範。

## 總結：最貼「暗夜花海 × 琉璃新藝術」嘅 Top 3（值得 ego-browser 逐站拆解）

1. **Lalique（lalique.com）** —— 琉璃新藝術**正源**：René Lalique 係 Art Nouveau 琉璃宗師，佢站嘅黑金 + 藤蔓 filigree + 水晶折射，係我哋「琉璃新藝術 + 金繕金絲」最字面嘅落地參照。拆解重點：**Art Nouveau 線條點做、琉璃材質點演、黑金比例**。
2. **Van Cleef & Arpels（vancleefarpels.com）** —— 花海 × 珠寶 × Art Nouveau 三合一：自然花卉母題 + 珠寶 SSS 透光 + Art Nouveau 花枝線條，直接對應「暗夜花海 × 琉璃光」。拆解重點：**花卉母題點樣做唔老土、SSS 光感、敘事構圖**。
3. **Diptyque（diptyqueparis.com）** —— 暗夜花海 + 燭光自發光：暗底 + 燭光式 rim light + 單一 spotlight，係我哋「bioluminescence 由內自發光」最直接嘅品牌示範。拆解重點：**光源方向（由內透出 vs 頂光）、暗色層次、留白**。

> 補強（非逐站，但要扒 code）：**Swarovski / Lusion** 嘅折射焦散（caustics）同 WebGL 玻璃 shader，係 spec §七「鏡面無限反射／琉璃折射／水面焦散」三項特效嘅**現成技術源**，同 Top 3 一齊開嚟做「視覺拆解 + 技術拆解」兩軌。
