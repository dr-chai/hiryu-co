# HIRYU 字體＋配色研究 — 暗夜花海（藍紫版／幽玄／冷冽 優先）

> 研究員：Deep（視覺設計研究 agent）
> 日期：2026-09-19
> Mood 已定格：**藍紫版（幽玄／靜止）** —— 紫晶透光 `#845EC2` + 琉璃青藍焦散 `#00B4D8` 做主，緋紅 `#FF2A4D` 降做極少點綴。
> 字體方向：**空靈、冷冽、文人**。
> 對比度全部以 **WCAG 2.x** 公式實測（`(L1+0.05)/(L2+0.05)`），非估數。

## A. 字體

### A1. 拉丁 Display —— Art Nouveau 感／極細襯線

**結論：`Cormorant Garamond` Light 300 Italic 係最啱「幽玄 × 新藝術」嘅免費選擇；要真正 hairline 字標（wordmark）加 `Italiana`；要 ultimate 編輯奢侈感先考慮付費 `PP Editorial New`。**

| 字體 | 來源 | 授權 | 點評（針對「幽玄 × 新藝術 × 冷冽」） |
|---|---|---|---|
| **Cormorant Garamond**（Light 300 / Italic） | [Google Fonts](https://fonts.google.com/specimen/Cormorant+Garamond) · [GitHub Catharsis Fonts](https://github.com/catharsisfonts/cormorant) | OFL（免費商用） | **首選**。高對比極細襯線、優雅空靈，45 個字檔 9 種風格，Light Italic 最「幽玄」。比 PP Editorial New 更冷、更靜。 |
| **Italiana**（Regular，天生極細） | [Google Fonts](https://fonts.google.com/specimen/Italiana) | OFL | 短大寫字標最啱：近乎 hairline，時裝／編輯感，可做「HIRYU」logo 副標。字重單一（只有 Regular），唔啱長文。 |
| **Marcellus** | [Google Fonts](https://fonts.google.com/specimen/Marcellus) · [CTAN](https://ctan.org/pkg/marcellus?lang=en) | OFL | 羅馬碑刻 flare-serif，莊嚴；但**只有 Regular + small-caps**，做唔到極細層級，做「輝琉」二字小楷副題尚可。 |
| **Fraunces**（variable） | [Google Fonts](https://fonts.google.com/specimen/Fraunces) · [設計說明](https://design.google/library/a-new-take-on-old-style-typeface) | OFL | 新藝術「柔軟／古怪」路線；但偏暖偏甜，同「冷冽幽玄」有啲衝突，適合少量詩句點綴，唔做主標。 |
| **Arnold Böcklin / Bocklin** | 唔喺 Google Fonts；[Fontspace（Bocklin by George Williams, 100% free）](https://www.fontspace.com/category/art-nouveau) · [Luc Devroye Art Nouveau 總表](https://luc.devroye.org/artnouveau.html) | 免費用 | 真正 Jugendstil 新藝術字，但**好華麗好重**（turn-of-century 海報風），同「空靈冷冽」相反。只建議 logo ／ 極細裝飾線用一格，唔好做正文或大標。 |
| **PP Editorial New** | [Pangram Pangram](https://pangrampangram.com/products/neue-montreal)（$40 起，免費試用） | 付費 | 編輯感最強嘅高對比 serif，但**商業站要買 license**。預算允許先揀佢；否則 Cormorant 已夠。 |

**安裝（Google Fonts）**：`<link href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,300;0,400;1,300&family=Italiana&display=swap" rel="stylesheet">`；或 [Fontsource](https://fontsource.org/) 自 host（`npm i @fontsource/cormorant-garamond`）。

### A2. 中文 Display —— 「幽玄／文人冷冽」嘅明體／宋體

**結論：`源樣明體`（GenYoMin）Light 係「文人冷冽」最強免費明體；要保證粵語用字覆蓋就揀 `思源宋體 HK / Noto Serif CJK HK`；想加溫度／手寫感先用 `霞鶩文楷`（注意：佢係楷體，唔係明體）。**

| 字體 | 來源 | 授權 | 點評 |
|---|---|---|---|
| **源樣明體（GenYoMin）** | [GitHub ButTaiwan/genyo-font](https://github.com/ButTaiwan/genyo-font) | SIL OFL 1.1（可商用） | **首選**。基於思源宋體、改用韓文（KR）字樣＋繁體置中標點，印刷體／文人感更強，比原版思源宋體「冷冽」。同作者仲有兄弟款 **源流明體**（[genryu-font](https://github.com/ButTaiwan/genwan-font) 同族）同 **源雲明體**（[genwan-font](https://github.com/ButTaiwan/genwan-font)）可一併試。 |
| **思源宋體 / Noto Serif CJK** | [adobe-fonts/source-han-serif](https://github.com/adobe-fonts/source-han-serif) · [Google Fonts Noto Serif](https://fonts.google.com/noto) | OFL | 底線選擇，7 字重（ExtraLight/Light 最啱幽玄）。**HK 變體覆蓋香港增補字符集（HKSCS）+ 粵語用字（嘅／噉／喺／啲）**，做正體粵語正文必備。 |
| **霞鶩文楷（LXGW WenKai）** | [GitHub lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai) · 繁版 [LxgwWenkaiTC](https://github.com/lxgw/LxgwWenkaiTC) | SIL OFL 1.1（可商用） | **楷體**（基於 Fontworks Klee One），唔係明體。手寫／文人／溫度感最強，適合詩句、宣言「廢而不頹，碎而有光」做手寫落款式點綴，唔做主排版。 |
| **芫荽（Iansui）** | [GitHub ButTaiwan/iansui](https://github.com/ButTaiwan/iansui) | SIL OFL 1.1 | 基於 Klee One 嘅台灣硬筆楷書，學習字型風，偏「手寫教育」多過「幽玄」，可做暖調後備。 |

> ⚠️ **「港版明體」澄清**：冇一個以「港版明體」命名嘅成熟開源專案。香港場景嘅正路係 **思源宋體 HK / Noto Serif CJK HK**（HKSCS 覆蓋）。源樣明體用 KR 字樣，**正式上線前要核實粵語專用字（嘅噉喺啲嚟咗）有冇缺字**；缺就先補 Noto Serif CJK HK 做 fallback。

**安裝（中文 self-host 必做 subsetting，見 A4）**：由 GitHub Releases 下載 `.ttf/.otf` → pyftsubset 壓縮 → 放 `public/fonts/`。

### A3. 正文／UI 拉丁 —— 冷靜黑體

**結論：免費冷靜黑體首選 `Geist`（或 `Instrument Sans`）；`PP Neue Montreal` 要買 license，唔值為電商正文課金；`Inter Tight` 做 dense UI 後備。**

| 字體 | 來源 | 授權 | 點評 |
|---|---|---|---|
| **Geist**（Vercel） | [Google Fonts](https://fonts.google.com/specimen/Geist) | OFL | **首選正文／UI**。乾淨中性 grotesque、專為產品介面造，冷而靜，同幽玄底最夾。 |
| **Instrument Sans** | [Google Fonts](https://fonts.google.com/specimen/Instrument+Sans) | OFL | 中性 grotesque，比 Geist 多少少銳利個性，startup／品牌 UI 用。 |
| **Space Grotesk** | [Google Fonts](https://fonts.google.com/specimen/Space+Grotesk) · [Florian Karsten](https://fonts.floriankarsten.com/space-grotesk) | OFL | 帶 tech／幾何個性，**唔建議做長正文**，只做細字標籤／價格。 |
| **Inter Tight** | [Google Fonts](https://fonts.google.com/specimen/Inter+Tight) | OFL | 現 spec 已用，legibility 最強，做 checkout／表格 dense 字後備。 |

### A4. 中文 Subsetting（self-host 子集化）

用 [fontTools `pyftsubset`](https://fonttools.readthedocs.io/en/latest/subset/)。中文全字庫一個 `.otf` 成 15–30MB，必須切。**最佳做法：由「站點實際用字」生成字表，唔好用全 CJK block**（簡繁喺同一 Unicode block 交叉，[全區間切唔到真省](https://www.imaegoo.com/2020/chinese-font-compress/)）。

```bash
pip install fonttools brotli

# 1) 收集站點實際用字 → unicodes.txt（每字一行，或一行連續）
#    例如由 build 輸出 / 文案檔抽取，含粵語專用字 + 常用標點

# 2) 子集化做 woff2
pyftsubset SourceHanSerifTC-Light.otf \
  --output-file=SourceHanSerifTC-subset.woff2 \
  --flavor=woff2 \
  --unicodes-file=unicodes.txt \
  --no-hinting \
  --layout-features='*'
```

**若走區間式（粗切，適合 demo）：**

```bash
pyftsubset SourceHanSerifTC-Light.otf \
  --output-file=shs-cjk.woff2 \
  --flavor=woff2 \
  --unicodes=U+4E00-9FFF,U+3400-4DBF,U+3000-303F,U+FF00-FFEF \
  --no-hinting
```

**CSS 用 `unicode-range` 分檔載入**（瀏覽器按實際文字只拉需要嗰檔）[參見 web-font subsetting 實務](https://machs.space/posts/web-font-optimization-subsetting-fonts/)：

```css
@font-face {
  font-family: "HIRYU-Serif";
  src: url("/fonts/shs-latin.woff2") format("woff2");
  unicode-range: U+0000-00FF;
}
@font-face {
  font-family: "HIRYU-Serif";
  src: url("/fonts/shs-cjk.woff2") format("woff2");
  unicode-range: U+4E00-9FFF, U+3400-4DBF, U+3000-303F, U+FF00-FFEF;
}
```

> 生產建議：拉丁一份（`U+0000-00FF`）、CJK 用**實際字表**一份、標點全形一份；繁體版記得加埋 `U+3000-303F`（中文標點）同 `U+FF00-FFEF`（全形）。Next.js 直接 `import './fonts.css'` 放 `app/`。

## B. 配色 Refine

### B0. 對比度實測表（WCAG）

| 前景 | 背景 | 對比度 | AA 正文(≥4.5) | AA 大字(≥3.0) | 用途判定 |
|---|---|---|---|---|---|
| 琉璃骨白 `#F7F4EA` | 玄青黑 `#080B10` | **17.91** | ✅ | ✅ | 正文／主標（AAA） |
| 緋紅 `#FF2A4D` | 玄青黑 `#080B10` | **5.34** | ✅ | ✅ | **AA 過關**，只做小字點綴／按鈕文字 |
| 紫晶 `#845EC2` | 玄青黑 `#080B10` | **4.09** | ❌ | ✅ | **正文唔夠 AA**，只做大字／圖形光 |
| 紫晶透光 `#B39DDB` | 玄青黑 `#080B10` | **8.22** | ✅ | ✅ | **紫字正文用呢隻** |
| 紫晶透光(亮) `#C4B5FD` | 玄青黑 `#080B10` | **10.67** | ✅ | ✅ | 高亮／hover 文字 |
| 琉璃青藍 `#00B4D8` | 玄青黑 `#080B10` | **7.99** | ✅ | ✅ | 焦散光／連結文字（近 AAA） |
| 骨白 `#F7F4EA` | 夜幕青紺 `#1E2749` | **13.24** | ✅ | ✅ | 卡片／浮層白字 |
| 琉璃青藍 `#00B4D8` | 夜幕青紺 `#1E2749` | **5.91** | ✅ | ✅ | 青紺底上青藍字 |
| 紫晶 `#845EC2` | 夜幕青紺 `#1E2749` | **3.03** | ❌ | ✅ | 青紺底上紫字要用透光版 |
| 新藝術金絲 `#E2C076` | 玄青黑 `#080B10` | **11.29** | ✅ | ✅ | 金繕細線／logo 點睛 |
| 舊金 `#B08A3E` | 玄青黑 `#080B10` | **6.15** | ✅ | ✅ | 舊金實體點綴 |
| 緋紅 `#FF2A4D` | 骨白 `#F7F4EA` | 3.35 | ❌ | ✅ | 淺底上緋紅只做大字 |
| 金（任何） | 骨白 `#F7F4EA` | 1.59–2.91 | ❌ | ❌ | **金一定唔好放淺底**，只用喺黑底 |

### B1. 對比度判定（直接答）

1. **緋紅 `#FF2A4D` on 玄青黑 `#080B10` 做文字夠唔夠 AA？** → **夠。5.34:1，過 AA 正文（≥4.5）**，但唔夠 AAA（≥7.0）。既然緋紅已降做極少點綴，呢個數完全冇問題；反而要留意：**紫晶 `#845EC2` 做主色先係對比度隱患（4.09，正文唔過 AA）**，紫字正文要換透光版 `#B39DDB`。

2. **黑嘅變體（補深度）**：三隻全部係「背景層」黑，唔做文字：

| Token | Hex | 定位 |
|---|---|---|
| 墨黑（sumi 墨） | `#0E0C0A` | 中性微暖近黑，主背景到卡片嘅過渡層 |
| 黑紅（wine-black） | `#170A0E` | 酒紅近黑，僅餘嘅紅調深度（呼應舊緋紅 mood，可近乎刪） |
| 深啡黑（umber） | `#14100A` | 暖木／土系黑，加「香爐／古董」溫度 |
| （既有）夜幕青紺 | `#1E2749` | 冷調主過渡面，藍紫版主力 |

> 補充：藍紫版深度其實更應該靠**冷端**分層——`#080B10`（玄青黑）→ `#0C1020`（青黑過渡）→ `#1E2749`（夜幕青紺）→ 紫晶幽深 `#3B2E63`（可加）。暖黑（墨黑／深啡黑）留嚟點綴「香爐／舊物」細節，唔好溝淡冷調。

3. **舊金／金繕色**：`#E2C076` vs `#B08A3E` vs 其他。

| 色 | Hex | 黑底對比 | 性格 |
|---|---|---|---|
| 新藝術金絲 | `#E2C076` | 11.29 | 香檳／淡金，光感最強 = **「碎而有光」嘅光** |
| 舊金（old gold） | `#CFB53B` | 9.69 | 經典舊金，比 `#E2C076` 深、比 `#B08A3E` 亮 |
| 古金（antique） | `#C49A2C` | 7.51 | 古董金，最「香爐／舊招牌金漆」 |
| 舊金（bronze） | `#B08A3E` | 6.15 | 青銅／暗金，最沉，接近「生鏽古董金屬」 |
| 暴發戶金 | `#FFD700` | — | ❌ 禁用，太亮太俗 |

**建議：兩層金，唔好單一。**
- **金繕細線／琉璃裂縫／logo 點睛（主要）＝ `#E2C076`** —— 佢係「透光」嗰種淡金，正好表達「裂縫有光」，黑底 11.29 對比極穩。
- **舊金實體（香爐／金漆／徽章／價錢幣符）＝ `#B08A3E` 或 `#C49A2C`** —— 要「古董金屬」沉味時用，但只用喺黑底。
- 想一個中間值一次過兩用 → **`#CFB53B`（old gold）** 係最正統「舊金」折衷。
- **`#FFD700`／`#D4AF37` 唔好用**，一用就變婚禮／暴發戶，破壞「廢而不頹」。[Gold color 參考](https://en.wikipedia.org/wiki/Gold_(color)) · [Kintsugi palette](https://www.color-hex.com/color-palette/1059790)

## C. 最終 Token 建議（藍紫版優先，可直接交 coding agent）

```css
:root {
  /* 底（黑，混用做深度） */
  --ink:        #080B10;   /* 玄青黑（主背景，微冷藍） */
  --ink-sumire: #0C1020;   /* 青黑過渡（新增，冷端深度） */
  --plum:       #12090D;   /* 焦炭深紫黑（保留，暖端暗部） */
  --indigo:     #1E2749;   /* 夜幕青紺（卡片/漸變） */
  --violet-deep:#3B2E63;   /* 紫晶幽深（新增，藍紫版暗部） */
  --sumi:       #0E0C0A;   /* 墨黑（暖中性，香爐細節） */
  --wine:       #170A0E;   /* 黑紅（可近乎刪） */
  --umber:      #14100A;   /* 深啡黑（暖土細節） */

  /* 焦點（藍紫版主導） */
  --violet:     #845EC2;   /* 紫晶透光（大面積光／大字） */
  --violet-hi:  #B39DDB;   /* 紫晶清輝（紫字正文，AA 8.2） */
  --violet-bright:#C4B5FD; /* 高亮／hover */
  --cyan:       #00B4D8;   /* 琉璃青藍焦散（caustics，AA 8.0） */
  --crimson:    #FF2A4D;   /* 緋紅（極少點綴，AA 5.3） */

  /* 白 + 金 */
  --bone:       #F7F4EA;   /* 琉璃骨白（正文/高光，AAA） */
  --gold-line:  #E2C076;   /* 新藝術金絲（金繕細線，主） */
  --gold-old:   #B08A3E;   /* 舊金（古董實體，次） */
}
```

**字體 stack（CSS）**：

```css
--font-display-latin: "Cormorant Garamond", "Italiana", serif;   /* Light 300 Italic 主標 */
--font-display-cjk:   "GenYoMin", "Source Han Serif HK", "Noto Serif CJK HK", serif;  /* 源樣明體 Light */
--font-body:          "Geist", "Instrument Sans", "Inter Tight", sans-serif;  /* 冷靜黑體 UI */
--font-accent-cjk:    "LXGW WenKai", "Iansui", serif;   /* 楷書詩句點綴 */
```
