## ⚠️ 跨章要實測／有衝突位（唔好盲抄）

1. **tracking 方向**：書負 tracking（−2%/−6%）針對粗體 sans 大標；HIRYU 用 Light 300 Italic 全大寫／中文大字，書另一條 rule 係「全大寫／細字加 tracking」。→ 兩條相反，要自己對住字逐級試（P0 #6）。
2. **中文行高 vs 書英文值**：書 baseline 例子係英文（16/24）。中文（思源宋體）通常要 1.6–1.8em 先夠疏。16px 正文行高 24px（1.5）對中文可能略密 → 試 26–29px 但要 keep baseline 倍數。
3. **字級層級斷崖**：HIRYU 主標 96–128px 對正文 16px 差 6–8 倍，中間要有 H2/H3（56/32/20）填補，唔好淨係兩級。
4. **配色係「feel 啱」唔係死跟 WCAG**：書講「Tweak, experiment, refine until it feels right」+「WCAG 非教條」（白字肉眼易讀但 WCAG 2.64 vs 黑字難讀但 4.5 嘅對照）。對比度表係起點，唔係鎖死；但文案＋CTA 一定要過 4.5:1。
5. **書冇嘅數，唔好作**：書**冇** hero 高度（vh）、section padding px、按鈕圓角、摺疊線比例、0.25em tracking、1.618 黃金比例、色相環度數（180/120/90/30°）。以上都要自己實測，唔好寫死。
