## 沉澱格式（每章一致）

每章沉澱檔固定五段：
1. **核心法則**（呢章最重要嘅 5–8 條原則，一句話一條）
2. **具體數字規格**（字號 px／間距／比例／色值／字重——可直接抄落 CSS 嘅 spec）
3. **常見錯誤**（書入面講嘅負例）
4. **落地 HIRYU checklist**（呢章可點反哺心喬 Summer 藍紫版）
5. **原文金句**（值得記嘅原句）
