## 1. 核心法則

1. **視覺元素有四大職責**——令內容易消化、打破大段文字嘅沉悶、吸睛、快速傳意但唔會令用戶「資訊過載」（p324）。
2. **五步創作流程**——①揀一個功能/主題/區塊 → ②列核心關鍵字 → ③搵靈感（Pinterest／Dribbble／X／mobbin）→ ④融合成一件獨特嘢 → ⑤確保符合你揀咗嘅風格方向（p324）。
3. **多數時候唔需要複雜視覺，要嘅係「令簡單嘢睇落簡單」嘅天賦**——書原句：你甚至唔需要複雜嘢，但你需要 talent 令佢睇落簡單（p323）。
4. **額外視覺元素 = 更有趣 + 更易消化**——「Extra visuals can make the design more interesting and digestible.」（p323）。
5. **SaaS 視覺 = 介面 UI 元素，唔使 exact replica**——而且「往往 simpler、less detailed 嘅視覺更好用」，俾訪客一個大概概念就夠，唔好 overwhelm（p327）。
6. **「簡化」係 SaaS 視覺嘅命門**——將一個功能/流程拆成 3–4 個簡單步驟/概念先至去視覺化（p329）；用高質 UI 元素＋微動畫傳達價值，唔使額外文字（p330）。
7. **用「佔位線」維持疏朗**——加 placeholder lines 表示「仲有更多資訊」，但唔會搶走主要訊息，成個畫面先至 spacious、uncluttered（p330）。
8. **一致性 = 全站重複你嘅「核心視覺 cue」**——重複特定元素（色／字體處理／陰影／描邊效果）、平衡多樣性與統一性、統一 UI 元素（按鈕／圖示／元件）（p340）。
9. **風格 = 五個反覆出現嘅關鍵要素**——特定效果（陰影／模糊／漸層／發光／線性填色與筆觸／不透明度／背景模糊）、調色盤、字體排印、版面配置、整體主題方向（p333）。
10. **顏色要「策略性用」，唔好「處處填背景色」**——一個 section 用主背景、另一個用彩色卡片、另一個用 stroke/小元素；深色卡片要喺其他位以互補方式重複，先至 tie 到成個設計（p335・p339）。

## 2. 具體數字規格

### 2.1 先講清楚：呢章冇 CSS 級數字

書呢章**完全冇俾**以下呢啲可直接抄落 CSS 嘅值：
- ❌ box-shadow 嘅 x／y／blur／spread／opacity
- ❌ border-radius px
- ❌ 透明度（opacity）具體數值
- ❌ 間距／padding／margin px
- ❌ 圖片比例／視覺重量比例
- ❌ 漸層嘅角度／色標位置

佢淨係**命名咗**要用邊啲效果、同埋要佢哋「跨區塊一致重複」，冇落到數字。呢個係章節嘅性質（講流程同方法論），唔係我漏抄。

### 2.2 書「命名咗」嘅特定效果（要全站一致，但書冇俾數字）

| 效果（書中名） | 原文提法 | 對 HIRYU 嘅意思 |
|---|---|---|
| 陰影 shadow | 風格關鍵要素之一 | 暗部極深要靠陰影／rim 分層 |
| 模糊 blur | 同上 | 背景模糊（background blur）獨立列咗出嚟 |
| 漸層 gradient | 「linear gradient fill & stroke」做特定 UI style | 琉璃「線性填色＋線性筆觸」 |
| 發光 glow | 風格關鍵要素之一 | 對應 volumetric glow／自發光 |
| 線性填色／筆觸 linear fill/stroke | p333・p334 明示 | 琉璃晶體邊要 gradient stroke |
| 部分不透明度 opacity | 「white opacity fill」／「black opacity fill」 | 透光 SSS 用 |
| 背景模糊 background blur | p333 明示 | 焦散／色散嘅柔化 |

> 書示範兩種樣式嘅效果差異：彩色版 = `white stroke + white opacity fill + blur`；黑白版 = `grey stroke + black opacity fill + blur`。即係同一組元素換 stroke 色＋fill 透明度＋blur，就係一套新風格。

## 3. 常見錯誤（書入面嘅負例）

1. **低品質、模糊嘅螢幕截圖／缺乏上下文嘅抽象視覺**——書明言「低品質嘅視覺會直接同低品質嘅產品掛鈎」（p329）。
2. **令人負擔過重、眼花撩亂嘅 UI**——一次過塞太多資訊，用戶 overwhelm（p329）。
3. **所有區塊佈局完全相同**——「將所有區塊都做成簡單嘅水平佈局、或成個站變成一組卡片」＝單調、消耗精力、令用戶失去興趣（p337）。
4. **成個站灰色、只喺首屏 keep 藍色背景**——書原例：呢個會「破壞一致性與整體風格」，因為隻藍色冇喺其他地方重複呼應（p338）。
5. **處處都填背景色**——書明言「simply adding a background color everywhere」係單調嘅做法，應該策略性分佈（p339）。
6. **過度追求複雜視覺**——書暗指反例：其實「多數時候你唔需要複雜嘢」，死撐複雜反而暴露冇 talent 令簡單嘢靚（p323）。

## 4. 落地 HIRYU checklist（心喬 Summer · mood 藍紫版）

> HIRYU 現視覺方向（真源 `品牌憲章-v3-暗夜花海.md`）：琉璃晶體 SSS 透光＋色散、水面焦散、金繕金絲、由內自發光（bioluminescence）、volumetric glow、rim light（暗部極深、邊緣極細極亮金／青輪廓光）。以下基於本章原則俾出「即刻改進／要核實」條目。

**即改／即核實：**

1. **「特定效果」要全站一致，唔好只有 hero 有**：書法則＝效果要「喺設計其他部分呼應」（p333）。核實 HIRYU 嘅 rim light／volumetric glow／色散係咪只喺首屏有、一落 shop／room／商品頁／結帳就變返 flat。書負例正正係「只有一處用、其他位冇呼應」＝破壞一致（p338）。
2. **藍紫 mood 要「策略性用色」，唔好成個站都填藍紫背景**：書 p339 教「一個 section 用主背景、另一個用彩色卡片、另一個用 stroke/小元素」。落地＝暗部極深（黑曜石底）做「主背景」角色、紫晶 `#845EC2`／青藍 `#00B4D8` 做「光軸 accent＋卡片」，金繕金絲做「stroke／小元素」級點綴。核實而家係咪「處處都係藍紫底」＝單調。
3. **深色卡片要互補重複**：書 p335——若用深 tone 卡片喺淺色站，要喺其他位用互補方式重複深 tone。HIRYU 反過嚟（深底站），即係若有「亮色區塊」做對比，要喺全站多於一處重複，唔好得一處亮。
4. **佈局多元但一致**：書 p337——HIRYU 有 hero＋2.5D 虛擬店（scroll＝上樓）＋product grid，要核實唔好「所有 section 都係卡片堆疊」；2.5D 上樓應係「垂直佈局但外觀多樣化」，同時共享同一網格／對齊／邊距（書範例 granola.ai 標註「Consistent Margins & spacing」）。
5. **每個商品／功能視覺拆 3–4 個簡單概念**：書 p329——HIRYU 9 件選物嘅「帶到光裡」轉場，每件要簡化做 3–4 步概念，唔好一次過塞晒細節（書：簡化 = 令訪客一眼 get 到，唔 overwhelming）。
6. **用「佔位線」維持幽玄留白**：書 p330——product 卡／note 式 UI 加 placeholder lines 表示「仲有更多」，維持 spacious、uncluttered（正正對應 HIRYU「幽玄·留白」方向）。
7. **微動畫用 2–3 個 state、subtle 就夠**：書 p330（3 states、optional）——HIRYU 色散／焦散／自發光配「3 個 state 嘅 subtle 動畫」做 clarity，唔好每個元素都郁（書話動畫係 optional、為「extra clarity」而加）。
8. **琉璃晶體用「linear gradient fill & stroke」**：書 p334 明示嘅特定 UI style——核實 HIRYU 按鈕／卡片邊係咪用 gradient stroke（琉璃質感）呼應，而唔係純實色邊；「漸層」係書點名要全站一致嘅效果。
9. **建立「效果 token」＝書嘅 ctrl+alt+c/v 落地版**：書 p334 tip（抄樣式捷徑）→ HIRYU 應該將 glow／rim／色散參數定義做 design token／utility class，一處定義、全站複用，先至保證「一致性」唔靠人肉 copy。
10. **選風格四考量對照 HIRYU**：書 p332–333——①目標受眾（廢佬選物店客群）②獨特性（港風頹廢×和風幽玄×琉璃新藝術本身夠獨特）③產品相容（日常選物店，非奢侈品牌）④趨勢（唔偏離主流太遠）。核實 mood 藍紫版係「夠獨特又唔係亂嚟」。
11. **字體一致性**：書 p336「Typography choice 定義 visual language，跨標題／正文／其他元素一致」——HIRYU 拉丁 display（Cormorant）＋中文 display（思源宋體）＋正文（Geist／Inter Tight）要核實喺全站所有 section 用同一套，唔好有啲 section 走咗第二隻字（可對照 `02-字體排版.md` checklist）。

## 5. 原文金句

1. 「Extra visuals can make the design more interesting and digestible.」（額外嘅視覺元素可以令設計更有趣、更易消化。— p323）
2. 「funny thing is that most of the time you don't even need complex things, but you need a talent to make it look simple.」（有趣嘅係，多數時候你甚至唔需要複雜嘢，但你需要一種令佢睇落簡單嘅天賦。— p323）
3. 「Often simpler, less detailed visuals work better.」（往往更簡單、細節更少嘅視覺效果更好。— p327）
4. 「To maintain a spacious, uncluttered look, I add placeholder lines to show there's extra info without distracting from the main idea.」（為咗維持疏朗、唔雜亂嘅觀感，我會加佔位線表示「仲有更多資訊」，同時唔搶走主要訊息。— p330）
5. 「Keeping design consistent means repeating your core visual cues throughout the website.」（保持設計一致，就係喺成個網站重複你嘅核心視覺線索。— p340）
