## 四、Next.js 16 關鍵 breaking changes（寫 code 前必記）

> 來源：`hiryu/node_modules/next/dist/docs/01-app/02-guides/upgrading/version-16.md`

1. **Turbopack 預設**：`next dev` / `next build` 預設用 Turbopack（唔使 `--turbopack`）。
2. **Async Request APIs**：`params`/`searchParams`/`cookies()`/`headers()`/`draftMode()` 全部要 `await`（同步訪問已移除）。
3. **`next lint` 已移除**：用 ESLint CLI 直接跑；`next build` 唔再 lint。
4. **middleware → proxy**：`middleware.ts` 改名 `proxy.ts`，函數 `middleware` → `proxy`，runtime 係 nodejs（唔支援 edge）。
5. **`next/image` 預設改**：`qualities` 淨 `[75]`、`minimumCacheTTL` 60s→4h、`imageSizes` 移除 16、local IP 預設 block、`maximumRedirects` 上限 3。
6. **Caching**：`revalidateTag` 要第 2 參數（`'max'` 等 cacheLife profile）；新增 `updateTag`（read-your-writes）、`refresh`；`cacheLife`/`cacheTag` 轉 stable。
7. **React Compiler**：stable，`reactCompiler: true` 可開（但唔預設開）。
8. **PPR → `cacheComponents`**：`experimental_ppr` 移除。
9. **`serverRuntimeConfig`/`publicRuntimeConfig` 移除**：用 env var。
10. **Scroll behavior**：Next 16 唔再自動 override 你嘅 `scroll-behavior: smooth`（要 override 就加 `data-scroll-behavior="smooth"`）。
